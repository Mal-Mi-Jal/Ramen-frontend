# 🍜 RamenLog

**"먹어본 사람만 리뷰할 수 있다"** — GPS와 체류 시간으로 방문을 인증해야 리뷰를 쓸 수 있는 라멘 맛집 리뷰 서비스입니다.

이 저장소는 **프론트엔드**입니다. 백엔드(Kotlin · Spring Boot)는 비공개 저장소로 관리하며, 아래에 구조와 구현 내용을 함께 정리했습니다.

> ⚠️ **현재 상태**: 백엔드 서버(Railway)의 이용 기간이 끝나서 [배포 사이트](https://ramen-frontend.vercel.app)의 로그인·조회 기능은 동작하지 않습니다. 화면 구성만 확인할 수 있습니다.

`2026.06 ~ 2026.09 · 개인 프로젝트 (기획 · 백엔드 · 프론트엔드)`

## 주요 기능

| 기능 | 내용 |
|---|---|
| 📍 **방문 인증** | 라멘집 반경 안에 들어가면 인증 시작 → 일정 시간 체류하면 인증 완료 → 리뷰 작성 가능 |
| 🗺️ **지도 · 검색** | 카카오맵으로 주변 라멘집 탐색, 가게명·지역명 키워드 검색 |
| ⭐ **리뷰** | 별점, 재방문 의사, 사진 업로드 (방문 인증된 사용자만) |
| 💬 **커뮤니티** | 리뷰 댓글, 추천(좋아요) |
| 👤 **내 기록** | 방문 기록(가게별 방문 횟수), 즐겨찾기, 프로필 |

### 방문 인증 흐름

```
[ 라멘집 반경 진입 ] ─▶ [ 인증 시작 (PENDING) ] ─▶ [ 체류 시간 충족 ] ─▶ [ 인증 완료 (VERIFIED) ] ─▶ [ 리뷰 작성 가능 ]
```

- 기준은 **반경 50m · 체류 20분**이며, 코드 수정 없이 **환경 변수로 조정**할 수 있습니다(혼자 테스트할 때는 로컬에서만 조건을 완화).
- 지나가다 잠깐 들른 경우를 걸러내려고 체류 시간 조건을 넣었습니다. 더 확실한 수단으로 **영수증 OCR 인증**을 계획하고 있습니다.

## 구현 포인트

### 백엔드
- **GPS 방문 인증**: 하버사인 공식으로 사용자와 가게 사이 거리를 계산하고, 인증 상태(대기 → 완료)를 관리합니다. `@Scheduled` 작업이 체류 시간을 채운 인증을 자동으로 완료 처리하고 방문 횟수를 누적합니다. 반경과 체류 기준은 설정값으로 분리했습니다.
- **라멘집만 골라내는 검색**: 카카오 장소 검색에 검색어를 확장해("○○", "○○ 라멘", "○○ 일본라멘") 여러 번 조회한 뒤, 업종 분류의 **마지막 단계가 "일본식라면"과 정확히 일치**하는 곳만 남깁니다. 공백을 무시한 가게명 매칭, DB 결과와 병합·중복 제거 후 **이름 일치 → 거리순**으로 정렬합니다.
- **외부 API 호출 줄이기**: 검색으로 찾은 가게를 DB에 저장해 두고, 주변 가게 조회는 DB만 사용합니다. 검색어에 이미 "라멘"이 있으면 검색어 확장을 생략합니다.
- **인증 · 에러 처리**: JWT Access/Refresh 토큰(Refresh 토큰은 DB 저장), 도메인 예외 12종과 전역 예외 처리기로 에러 응답 형식을 통일했습니다.
- **테스트**: JUnit5 + Mockito로 인증 반경·체류 시간의 **경계값**과 로그인 흐름을 검증합니다. 반경 바로 안(약 40m)과 바로 밖(약 60m)을 검사하는 테스트를 추가하다가, 인증 완료 단계에만 테스트용 반경이 남아 있던 문제를 찾아 고쳤습니다. 기존 테스트는 거리 0m만 검사해서 이 차이를 잡지 못했습니다.
- **배포**: Docker 멀티스테이지 빌드(JDK로 빌드 → JRE로 실행), 비밀 값은 환경 변수로 분리했습니다.

### 프론트엔드
- **조회 캐시와 무효화**: 가게 상세, 주변 목록, 프로필, 방문 기록을 메모리에 캐시해 같은 화면을 다시 열 때 API를 호출하지 않습니다. 리뷰를 작성·수정·삭제하면 관련 캐시를 지워서 오래된 정보가 보이지 않게 했습니다.
- **로그인 유지**: 앱을 다시 열 때 저장된 Access 토큰이 만료돼 있으면 Refresh 토큰으로 재발급받아 로그인 상태를 이어갑니다.

## 알고 있는 한계

- 인증 시작 후에는 위치를 다시 확인하지 않아서, 들어갔다 바로 나가도 시간이 지나면 인증될 수 있습니다. → 영수증 OCR 인증으로 보완할 계획입니다.
- 주변 가게 조회가 저장된 가게 전체를 불러와 거리를 계산합니다. 데이터가 많아지면 위경도 범위 조건이나 공간 인덱스로 DB에서 먼저 걸러야 합니다.
